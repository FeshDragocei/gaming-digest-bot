# 🎮 Игровые новости — Telegram-бот

Бот следит за игровыми сайтами (StopGame, Игромания, DTF, 3DNews, IGN, PC Gamer,
GameSpot и др.) и публикует в Telegram-канал самые интересные новости
**по мере их появления** — проверка каждые 30 минут.

- Релизы и анонсы, события индустрии, необычные факты
- Скидки, распродажи и раздачи
- Каждая новость — отдельный пост: картинка + короткий пересказ из статьи (2–4 предложения)
- Зарубежные новости автоматически переводятся на русский
- За одну проверку — от 1 до 5 новостей; между постами пауза 3–5 минут
- Не больше одной новости на тему за проверку и до 4 за сутки — без ГТА-флуда

## Шаг 1. Создайте бота в @BotFather

1. Откройте в Telegram бота **@BotFather**
2. Отправьте команду `/newbot`
3. Введите **имя** бота (любое, например «Gaming Digest»)
4. Введите **username** — должен заканчиваться на `bot`, например `my_gaming_digest_bot`
5. BotFather пришлёт **токен** вида `1234567890:AAHfk2...` — сохраните его

## Шаг 2. Создайте канал и добавьте бота

1. Создайте канал (или используйте существующий)
2. Добавьте бота **администратором** канала (достаточно права «Публиковать сообщения»)
3. Узнайте **ID канала** — два способа:
   - **Легко:** напишите боту `@username_вашего_бота` команду `/chatid` — он покажет ID чата;
     или отправьте `/chatid` прямо в канал (бот должен быть админом)
   - Публичный канал вместо ID: можно вписать просто `@имя_канала`

## Шаг 3. Настройте проект

```bash
cd gaming-news-bot

# виртуальное окружение (Windows)
python -m venv .venv
.venv\Scripts\activate

# зависимости
pip install -r requirements.txt
```

Скопируйте `.env.example` в `.env` и заполните:

```ini
BOT_TOKEN=1234567890:AAHfk2...      # токен из BotFather
CHANNEL_ID=-1001234567890           # или @имя_канала
CHECK_INTERVAL_MINUTES=30           # как часто проверять новости (минуты)
FRESH_HOURS=12                      # сколько часов назад искать новости
TIMEZONE=Europe/Moscow
```

## Запуск 24/7 без вашего компьютера

Основной способ — **GitHub Actions (бесплатно навсегда)**: дайджесты приходят
в канал дважды в день, сервер и включённый ПК не нужны.
Пошаговая инструкция: **[DEPLOY_GITHUB.md](DEPLOY_GITHUB.md)**

Локальный запуск (для тестов и команд `/digest`) — ниже.

## Шаг 4. Запуск

```bash
python bot.py
```

Готово — бот будет проверять новости каждые 30 минут и публиковать их в канал
по мере появления. Также бот отвечает в личке на команды:

| Команда   | Действие                                   |
|-----------|--------------------------------------------|
| `/start`  | приветствие и список команд                |
| `/digest` | проверить и опубликовать следующую новость |
| `/chatid` | показать ID текущего чата/канала           |

## Полезно знать

- **Проверить, какие ленты живы:** `python scripts/check_sources.py`
- **Посмотреть, какие новости попадут в следующий выпуск (без публикации):**
  `python scripts/preview_digest.py`
- **Добавить свои источники:** откройте `sources.py` и добавьте RSS-ссылку
  (для зарубежных укажите `lang: "en"` — они переведутся автоматически)
- **Временно отключить источник:** поставьте `"enabled": False` в `sources.py`
- **Защита от повторов:** опубликованные новости запоминаются в `data/seen_news.json`.
  Если что-то пошло не так — удалите файл, новости «разблокируются»
- **Частота проверки:** `CHECK_INTERVAL_MINUTES=30` в `.env` (или cron в workflow для GitHub)

## Автозапуск

**Windows:** Планировщик задач → задача → действие:
`C:\...\gaming-news-bot\.venv\Scripts\python.exe bot.py`
рабочая папка: `C:\...\gaming-news-bot`

**VPS (Linux):** systemd-сервис или `screen`/`tmux`; боту нужен только исходящий интернет.

## Структура проекта

```
gaming-news-bot/
├── bot.py                # точка входа: бот, команды, планировщик
├── config.py             # конфигурация (.env)
├── sources.py            # список RSS-источников ← редактируйте под себя
├── news.py               # загрузка лент, картинки (og:image из статей)
├── digest.py             # отбор интересного, дедупликация, перевод, текст поста
├── publish.py            # публикация в канал (альбом фото / текст)
├── scripts/check_sources.py  # проверка доступности лент
├── scripts/preview_digest.py # предпросмотр дайджеста без публикации
├── data/seen_news.json   # история опубликованного (создаётся сама)
└── .env                  # токены и настройки (создаётся из .env.example)
```
