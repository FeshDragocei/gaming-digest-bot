# 🚀 Запуск бота 24/7 через GitHub Actions (бесплатно)

Бот будет жить на GitHub: каждые 30 минут сервис сам проверяет игровые
сайты на свежие интересные новости (релизы, анонсы, события, скидки)
и публикует их в ваш канал — по одной за проверку, по мере появления.
Ваш компьютер не нужен вовсе.

**Как это работает:** GitHub запускает `scripts/publish_now.py` →
бот собирает новости, выбирает самую интересную из ещё не показанных,
публикует её постом (фото + пересказ) и сохраняет список уже показанных
новостей обратно в репозиторий. Если новостей накопилось много — они
выходят постепенно, по одной за проверку.

---

## Шаг 1. Аккаунт GitHub

Если аккаунта нет — зарегистрируйтесь на [github.com](https://github.com) (бесплатно).

## Шаг 2. Создайте репозиторий

1. Откройте [github.com/new](https://github.com/new)
2. Repository name: например `gaming-digest-bot`
3. Выберите **Private** (приватный — код и история видны только вам)
4. Ничего не добавляйте (без README) → **Create repository**
5. Скопируйте ссылку репозитория, она вида:
   `https://github.com/ВАШ_ЛОГИН/gaming-digest-bot.git`

## Шаг 3. Загрузите код (выполняется на вашем ПК, один раз)

Откройте PowerShell и выполните по очереди:

```powershell
cd "C:\Users\FeshD\Documents\Default Project\gaming-news-bot"

git init
git add .
git commit -m "Игровой дайджест: первая версия"
git branch -M main
git remote add origin https://github.com/ВАШ_ЛОГИН/gaming-digest-bot.git
git push -u origin main
```

При первом `git push` откроется окно входа в GitHub — войдите и разрешите доступ.
Файл `.env` с токеном **не загружается** — он защищён через `.gitignore`.

## Шаг 4. Добавьте секреты (токен и канал)

Токен бота хранится не в коде, а в защищённых «секретах» репозитория:

1. Откройте ваш репозиторий → **Settings** → **Secrets and variables** → **Actions**
2. Нажмите **New repository secret**
3. Создайте два секрета:
   - Name: `BOT_TOKEN` → Secret: ваш токен бота (`9196120330:AAE...`)
   - Name: `CHANNEL_ID` → Secret: `-1003912277642`

## Шаг 5. Разрешите workflow сохранять историю

1. В репозитории: **Settings** → **Actions** → **General**
2. Прокрутите до **Workflow permissions**
3. Выберите **Read and write permissions** → **Save**

Это нужно, чтобы бот запоминал уже опубликованные новости (иначе будут повторы).

## Шаг 6. Проверка

1. Откройте вкладку **Actions** в репозитории
2. Слева выберите **«Игровые новости»**
3. Справа нажмите **Run workflow** → **Run workflow**
4. Через минуту в вашем канале появится свежая новость 🎉

## Шаг 7. Остановите локального бота

Чтобы дайджесты не дублировались, остановите копию бота на вашем ПК.
Проще всего написать мне «останови бота» — или выполнить:

```powershell
Stop-Process -Id 35636
```

## Частые вопросы

**Проверка была в 10:07, а не ровно в 10:00?**
GitHub запускает по расписанию с задержкой до 5–15 минут — это нормально.

**Как изменить частоту проверки?**
Откройте `.github/workflows/digest.yml` в репозитории (можно прямо на сайте,
карандашик «Edit») и поменяйте строку cron. Сейчас: `7,37 * * * *` — проверка
дважды в час. Например:
- `13 * * * *` — раз в час (экономнее)
- `7,22,37,52 * * * *` — каждые 15 минут (чаще; см. про лимит минут ниже)

**Как выпустить новость вручную?**
Вкладка Actions → «Игровые новости» → Run workflow. Это замена команды `/digest`.

**Как добавить/убрать источники?**
Отредактируйте `sources.py` и сделайте commit & push (или правьте прямо на сайте).

**Сколько это стоит?**
Для приватного репозитория GitHub даёт 2000 минут Actions в месяц — при
проверке каждые 30 минут этого впритык. Чтобы снять лимиты полностью,
можно сделать репозиторий публичным (Settings → General → Danger Zone →
Change visibility → Public): в коде нет никаких секретов — токен лежит
в защищённых Secrets, так что публичность безопасна. Для публичных
репозиториев Actions бесплатен без лимитов.

**GitHub прислал письмо «Scheduled workflow is disabled»?**
Если вы не заходили в репозиторий 60 дней, GitHub ставит расписание на паузу.
Достаточно зайти в репозиторий и в Actions нажать «Enable workflow».
